Example 3:
Enter your query in natural language: Can you list the top 3 win ratios?
Generated SQL Query: WITH RaceCounts AS (
    SELECT hr.horse_id, COUNT(hr.race_id) AS total_races
    FROM HorseRaces hr
    GROUP BY hr.horse_id
),
WinCounts AS (
    SELECT r.first_place AS horse_id, COUNT(*) AS wins
    FROM Races r
    WHERE r.first_place IS NOT NULL
    GROUP BY r.first_place
)
SELECT h.name, COALESCE(wc.wins, 0) * 1.0 / rc.total_races AS win_ratio
FROM Horses h
JOIN RaceCounts rc ON h.horse_id = rc.horse_id
LEFT JOIN WinCounts wc ON h.horse_id = wc.horse_id
ORDER BY win_ratio DESC
LIMIT 3;
Query Results:
The top 3 win ratios are:
1. Thunder with a win ratio of 1.0
2. Lightning with a win ratio of 0.75
3. Storm with a win ratio of 0.5

Generated SQL Query: SELECT a.street_name, a.city, a.state, a.zip, COUNT(r.race_id) as race_count
FROM Races r

LIMIT 1;

Enter your query in natural language: What is the race that had the most horses. If there is a tie, display all of them.
Generated SQL Query: SELECT r.race_id, r.race_date, r.address_id
FROM Races r
JOIN (
    SELECT race_id, COUNT(horse_id) as num_horses
    FROM HorseRaces
    GROUP BY race_id
) hr ON r.race_id = hr.race_id
WHERE hr.num_horses = (
    SELECT MAX(horse_count) 
    FROM (
        SELECT race_id, COUNT(horse_id) as horse_count 
        FROM HorseRaces 
        GROUP BY race_id
    ) count_table
);
Query Results:
There is no tie; the race with the most horses is the one on March 14, 2026, which had 15 horses.
